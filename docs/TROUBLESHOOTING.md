# Troubleshooting

Real failures and their fixes, each from a script, a hook or a lesson already in this repo. See also
[TESTING.md](./TESTING.md), [LEARNINGS.md](./LEARNINGS.md) and [CONTRIBUTING.md](../CONTRIBUTING.md); for a running
system, [RUNBOOK.md](./RUNBOOK.md).

| Symptom                                                                                        | Cause and fix                                                                                                                                                                                                                                                      |
| :--------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cargo test` fails on a generated file (tokens, rules, screens, DESIGN.md)                     | A generated file is stale (ADR-0030). Run `pnpm tokens:sync`; never hand-edit the output. [DESIGN.md](./DESIGN.md)                                                                                                                                                 |
| Swift or Kotlin cannot find a UniFFI function, or parity tests fail after a Rust export change | Bindings are out of date. Run `pnpm uniffi:generate`. [CONTRIBUTING.md](../CONTRIBUTING.md)                                                                                                                                                                        |
| `pnpm test:rust:coverage` or `pnpm test:ts:coverage` fails below 100%                          | Add the missing test; do not lower thresholds or add excludes. A `const fn` used only in `const` items, or an async fn shared by several test binaries, can look uncovered: see the 2026-11-09 and 2026-11-10 (async fn) entries in [LEARNINGS.md](./LEARNINGS.md) |
| Commit is rejected by `commit-msg`                                                             | The header must be a Conventional Commit: `type(scope)!: subject`, for example `feat(web): show a loading state` (ADR-0034).                                                                                                                                       |
| Commit rejected by `pre-commit`                                                                | It runs `pnpm spec:check`, formatting, typecheck and clippy. Run `pnpm check:quick` to see them in seconds. Hooks are activated by `pnpm install` (`pnpm hooks:install` re-applies).                                                                               |
| `pnpm tooling:test` fails on a file over 800 lines                                             | Hand-written code and test files stay at or under 800 lines; split by responsibility. Generated files are exempt if their header says so.                                                                                                                          |
| `pnpm spec:check` fails                                                                        | A `[verified]` requirement has no citing test, or a test cites an unknown id. Cite it as `// Verifies: REQ-...`. [specs README](./specs/README.md)                                                                                                                 |
| iOS project is missing a new file, or `pnpm ios:build` ignores it                              | The Xcode project is generated. Run `pnpm ios:project` (XcodeGen) after adding or moving Swift files.                                                                                                                                                              |
| Android parity or screenshot tests fail with `UnsatisfiedLinkError` on a clean machine         | The host `tran-uniffi` build was never made. Gradle builds it through `buildHostRustLib`; see the 2026-10-22 "Green locally" entry in [LEARNINGS.md](./LEARNINGS.md).                                                                                              |
| `:app:assembleRelease` fails in lint although debug and tests pass                             | Only the release build runs `lintVitalRelease`. After adding an Android dependency run `./gradlew :app:assembleRelease`, and lift a stale transitive with a `constraints` entry.                                                                                   |
| Android UI test: "component is not displayed" only in CI                                       | The CI emulator is 320 x 640 dp. Reproduce on that profile; layout tests use `@GraphicsMode(NATIVE)` (`NarrowScreenTest`).                                                                                                                                         |
| Every later Compose test fails with "Compose did not get idle"                                 | Compose state was written outside a composition. Create it with its first value; call `Snapshot.sendApplyNotifications()` in `@After` otherwise.                                                                                                                   |
| Unit tests pass but the web app does not load, or `pnpm test:e2e` fails broadly                | A package the web bundle imports used a Node built-in (`browser-safe.test.ts` catches it). Run `pnpm test:all` before pushing such changes.                                                                                                                        |
| `pnpm smoke` reports a `script-src eval` CSP violation                                         | Import `z` from `packages/api/src/schemas/zod.ts` (sets `jitless`); never widen the policy.                                                                                                                                                                        |
| `pnpm audit` still lists an advisory after you added an override                               | pnpm 11 reads `overrides` only from `pnpm-workspace.yaml`, keyed by range (`'name@<fixed': '>=fixed'`).                                                                                                                                                            |
| Screen id guard (`screen-ids.test.ts`) fails on a comment or `data-testid`                     | It reads comments too. Name elements in plain words and compute conditional test ids into a variable.                                                                                                                                                              |
| A script's `main()` silently does not run from a temp folder                                   | Compare `import.meta.url` with `pathToFileURL(realpathSync(process.argv[1])).href` (macOS temp folders are symlinks).                                                                                                                                              |
| Screenshots differ, or a native formatting bug shows only in one locale                        | Run `pnpm ios:screenshots` / `pnpm android:screenshots` (references are local, never committed). Use machine formats (ISO 8601) for anything sent to Rust or the API (REQ-NAT-012).                                                                                |
